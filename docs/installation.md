# Installation

## Stable release

To install skeleton, run this command in your terminal:

```sh
uv add sk
```

Or if you prefer to use `pip`:

```sh
pip install sk
```

## From source

The source files for skeleton can be downloaded from the [Github repo](https://github.com/vibtrip/sk).

You can either clone the public repository:

```sh
git clone https://github.com/vibtrip/sk
```

Or download the [tarball](https://github.com/vibtrip/sk/tarball/main):

```sh
curl -OJL https://github.com/vibtrip/sk/tarball/main
```

Once you have a copy of the source, you can install it with:

```sh
cd sk
uv sync
```
